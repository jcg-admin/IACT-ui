2. Especificación
-----------------

**Declaración:**

   El sistema DEBE generar un password temporal seguro y mostrarlo en
   pantalla CUANDO la respuesta de seguridad ha sido validada exitosamente.

**Descripción:**

   El proceso de generación:
   
   1. Genera password aleatorio criptográficamente seguro
   2. Hashea el password con bcrypt
   3. Actualiza el hash en tabla ``users``
   4. Muestra password en pantalla (una sola vez)
   5. Marca cuenta para forzar cambio (FR-003.05)
   
   **Características del Password Temporal:**
   
   - Longitud: 12 caracteres
   - Composición: letras mayúsculas, minúsculas, números
   - Sin caracteres ambiguos: 0, O, l, 1, I
   - Ejemplo: "Kx7nP2mRq9Wy"
   
   **Visualización (BR_004):**
   
   Como el sistema NO envía emails externos, el password temporal
   se muestra directamente en pantalla. El usuario debe anotarlo
   antes de cerrar la ventana.

----

3. Criterio de Aceptación
-------------------------

::

   DADO respuesta de seguridad validada correctamente
   CUANDO el sistema genera password temporal
   ENTONCES se muestra en pantalla y se almacena hasheado
   
   Escenario 1: Generación exitosa
   DADO validación de respuesta exitosa
   CUANDO se genera password temporal
   ENTONCES se muestra password de 12 caracteres
   Y el password cumple requisitos de complejidad
   Y se actualiza hash en base de datos
   
   Escenario 2: Password mostrado una vez
   DADO password temporal generado
   CUANDO el usuario navega fuera de la página
   ENTONCES el password no se puede recuperar
   Y debe reiniciar proceso de recuperación si lo perdió
   
   Escenario 3: Password único cada vez
   DADO múltiples recuperaciones del mismo usuario
   CUANDO se genera password cada vez
   ENTONCES cada password es diferente y aleatorio

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:**
  - BR_004: Comunicaciones internas (password en pantalla, NO email)
  
- **CNST aplicables:**
  - CNST-005: Seguridad (generación criptográfica)

**Algoritmo de Generación:**

.. code-block:: python

   import secrets
   import string
   
   def generate_temp_password(length=12):
       # Excluir caracteres ambiguos
       alphabet = string.ascii_letters + string.digits
       alphabet = alphabet.replace('0', '').replace('O', '')
       alphabet = alphabet.replace('l', '').replace('1', '').replace('I', '')
       
       return ''.join(secrets.choice(alphabet) for _ in range(length))
