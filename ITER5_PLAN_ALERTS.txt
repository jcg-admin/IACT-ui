MÓDULO: MOD_Alerts - Sistema de alertas y notificaciones

Descripción:
- Configurar alertas basadas en condiciones
- Histórico de alertas disparadas
- Suscripciones y notificaciones
- Plantillas de alertas
- Canales de entrega (email, SMS, in-app)

ESTRUCTURA DATABASE
===================

TABLA: alerts
├─ id
├─ code (ALR-SYS-001, etc)
├─ name
├─ description
├─ category
├─ condition (JSON: {metric, operator, value})
├─ threshold
├─ is_active
├─ created_at
└─ updated_at

TABLA: alert_subscriptions
├─ id
├─ user_id
├─ alert_id
├─ channels (JSON: [email, sms, in_app])
├─ frequency (REALTIME, DAILY, WEEKLY)
├─ is_subscribed
├─ subscribed_at
└─ unsubscribed_at

TABLA: alert_history
├─ id
├─ alert_id
├─ triggered_at
├─ triggered_value
├─ status (SENT, PENDING, FAILED)
├─ recipients (JSON)
├─ message
└─ metadata (JSON)

TABLA: alert_templates
├─ id
├─ code
├─ name
├─ category
├─ description
├─ subject_template
├─ body_template
├─ condition_template (JSON)
└─ is_default

FLUJOS PRINCIPALES
==================

FLUJO 1: Crear Alerta (UC_ALR_02)
─────────────────────────────────

User -> AlertConfigPage
     -> Ingresa nombre, descripción
     -> Define condición (métrica, operador, valor)
     -> Selecciona canales (email, SMS, in-app)
     -> Define frecuencia
     -> Guarda

Backend:
├─ Valida condición
├─ Crea registro en alert_config
├─ Si es plantilla: copia template
└─ Response: alert ID

Frontend:
├─ Redux: addAlert
├─ Toast: "Alerta creada"
└─ Redirect a AlertsPage

FLUJO 2: Suscribirse (UC_ALR_04)
────────────────────────────────

User -> AlertsPage
     -> Click en "Suscribirse"
     -> Selecciona canales
     -> Selecciona frecuencia
     -> Guarda

Backend:
├─ INSERT en alert_subscriptions
├─ Envía confirmación
└─ Log en auditoria

Frontend:
├─ Redux: subscribeToAlert
├─ Toast: "Suscrito a alerta"

FLUJO 3: Ver Historial (UC_ALR_03)
──────────────────────────────────

User -> AlertHistoryPage
     -> Filtra por rango de fechas
     -> Filtra por tipo/categoría
     -> Ve tabla de disparos

Backend:
├─ Query con filtros
├─ Retorna 50 últimos disparos
└─ Incluye estado de entrega

Frontend:
├─ Redux: fetchAlertHistory
├─ Renderiza tabla
├─ Opción exportar CSV
