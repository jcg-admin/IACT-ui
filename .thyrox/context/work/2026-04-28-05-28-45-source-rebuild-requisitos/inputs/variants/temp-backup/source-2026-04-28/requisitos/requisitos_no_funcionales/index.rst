=========================
Requisitos No Funcionales
=========================

Propósito
=========

Este subdominio contiene los **Requisitos No Funcionales (RNF)** del proyecto IACT, 
estableciendo atributos de calidad que debe cumplir el sistema.

Los requisitos no funcionales definen cómo debe comportarse el sistema en términos 
de rendimiento, seguridad, usabilidad y otros atributos de calidad.

Contenido
=========

Los requisitos no funcionales incluyen:

* **Rendimiento:** Tiempos de respuesta, throughput
* **Seguridad:** Autenticación, autorización, encriptación
* **Usabilidad:** Facilidad de uso, accesibilidad
* **Disponibilidad:** Uptime, recuperación ante fallos
* **Escalabilidad:** Capacidad de crecimiento
* **Mantenibilidad:** Facilidad de modificación

Prefijo
=======

Los artefactos de este subdominio usan el prefijo **RNF_** (Non-Functional Requirement).

Ejemplo: ``RNF_001_Tiempo_Respuesta_Dashboard.rst``

.. note::
   Contenido en desarrollo. Los requisitos no funcionales se documentarán conforme 
   se establezcan los estándares de calidad del sistema.
