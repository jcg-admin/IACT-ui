PATTERN 2️⃣ : EVENT CLEANUP (Memory Leak Prevention)
────────────────────────────────────────────────────────────────────────────

Purpose:                Prevent memory leaks from accumulated event listeners
Current IACT Status:    ✅ 95% COMPLETE (Session 3 fixes)
Raid Party Status:      100% (every addEventListener has cleanup)
Effort:                 🟢 Low
Impact:                 🟢 HIGH (critical for production)
Priority:               🔴 HIGH (nearly done, just needs audit)

Implementation:
  useEffect(() => {
    // Setup
    const handler = (e) => { /* ... */ }
    window.addEventListener('event', handler)
    
    // CLEANUP (essential!)
    return () => {
      window.removeEventListener('event', handler)
    }
  }, [dependencies])

Fixed in Session 3:
  ✅ useMediaQuery       - addEventListener cleanup
  ✅ useClickAway        - document listener cleanup
  ✅ useThrottle         - interval cleanup
  ✅ useMediaQuery       - window listener cleanup

Potential Issues to Audit:
  ⏳ useForm            - Check for window listeners
  ⏳ useAsync           - Check for AbortController usage
  ⏳ Custom hooks       - General event listener review

Memory Leak Pattern (❌ DON'T DO THIS):
  useEffect(() => {
    window.addEventListener('resize', handler)
    // ❌ MISSING: No cleanup!
    // Result: 10 components = 10 zombie listeners
  }, [])

Correct Pattern (✅ DO THIS):
  useEffect(() => {
    window.addEventListener('resize', handler)
    return () => window.removeEventListener('resize', handler)
    // ✅ Cleanup removes listener on unmount
  }, [])
