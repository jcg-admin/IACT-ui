2. Especificación
-----------------

**Declaración:**

   El sistema DEBE validar que el nuevo password cumpla con las políticas
   de complejidad establecidas CUANDO el usuario lo ingresa.

**Descripción:**

   El nuevo password debe cumplir TODOS los requisitos:
   
   **Requisitos de Complejidad:**
   
   - Longitud mínima: 8 caracteres
   - Longitud máxima: 128 caracteres
   - Al menos 1 letra mayúscula (A-Z)
   - Al menos 1 letra minúscula (a-z)
   - Al menos 1 número (0-9)
   - Al menos 1 carácter especial (!@#$%^&*()_+-=[]{}|;:,.<>?)
   - No puede ser igual a los últimos 5 passwords usados
   - No puede contener el username
   - No puede ser un password común (lista de 10,000 más comunes)

----

3. Criterio de Aceptación
-------------------------

::

   DADO un usuario ingresando nuevo password
   CUANDO envía el formulario
   ENTONCES el sistema valida todas las reglas de complejidad
   
   Escenario 1: Password cumple todos los requisitos
   DADO password = "MiClav3$egura!"
   CUANDO se valida
   ENTONCES la validación pasa exitosamente
   
   Escenario 2: Password muy corto
   DADO password = "Ab1$"
   CUANDO se valida
   ENTONCES se muestra "Mínimo 8 caracteres"
   
   Escenario 3: Sin mayúscula
   DADO password = "mipassword123!"
   CUANDO se valida
   ENTONCES se muestra "Debe incluir al menos una mayúscula"
   
   Escenario 4: Password repetido
   DADO password igual a uno de los últimos 5
   CUANDO se valida
   ENTONCES se muestra "No puede reutilizar passwords recientes"
   
   Escenario 5: Password común
   DADO password = "Password123!"
   CUANDO se valida
   ENTONCES se muestra "Password demasiado común, elija otro"
