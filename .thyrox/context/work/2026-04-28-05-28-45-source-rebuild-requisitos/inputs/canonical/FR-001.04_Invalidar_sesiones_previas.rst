FR-001.04: Invalidar sesiones previas
=====================================

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE invalidar todas las sesiones activas previas del usuario
   CUANDO se inicia una nueva sesión exitosa, garantizando sesión única (BR_005).

**Descripción:**

   Antes de generar el nuevo token JWT, el sistema:
   
   1. Consulta tabla ``user_sessions`` para el user_id
   2. Identifica todas las sesiones con status = 'ACTIVE'
   3. Actualiza status a 'INVALIDATED' para todas las sesiones encontradas
   4. Registra timestamp de invalidación (invalidated_at)
   5. Registra motivo: 'NEW_LOGIN'
   
   Esto garantiza que un usuario solo puede tener una sesión activa
   a la vez, cumpliendo con la regla de negocio BR_005.

----

3. Criterio de Aceptación
-------------------------

::

   DADO un usuario con credenciales válidas que inicia sesión
   CUANDO el sistema procesa el login
   ENTONCES invalida todas las sesiones previas antes de crear la nueva
   
   Escenario 1: Usuario con sesión activa previa
   DADO usuario "juan.perez" con 1 sesión activa
   CUANDO inicia nueva sesión
   ENTONCES la sesión previa cambia a status = 'INVALIDATED'
   Y se crea nueva sesión con status = 'ACTIVE'
   
   Escenario 2: Usuario con múltiples sesiones (legacy)
   DADO usuario con 3 sesiones activas (caso anómalo)
   CUANDO inicia nueva sesión
   ENTONCES las 3 sesiones previas se invalidan
   Y se crea exactamente 1 nueva sesión
   
   Escenario 3: Usuario sin sesiones previas
   DADO usuario sin sesiones en user_sessions
   CUANDO inicia sesión
   ENTONCES no hay invalidaciones
   Y se crea nueva sesión normalmente

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:**
  - BR_005: Sesión única - Un usuario solo puede tener una sesión activa
  
- **CNST aplicables:**
  - CNST-002: Gestión de sesiones en BD

**Comportamiento Transaccional:**

- La invalidación y creación de nueva sesión deben ser atómicas
- En caso de error, se hace rollback completo
- Si falla la invalidación, no se crea nueva sesión
