==================
Project Management
==================

Propósito
=========

Este subdominio contiene la **documentación de gestión del proyecto** IACT, 
incluyendo planificación, cronogramas, seguimiento y control.

La gestión de proyecto proporciona visibilidad sobre el avance, riesgos 
y recursos del proyecto.

Contenido
=========

La gestión del proyecto incluye:

* **Plan de Proyecto:** Alcance, objetivos, estrategia
* **WBS:** Work Breakdown Structure (estructura de descomposición del trabajo)
* **Cronograma:** Timeline, hitos, dependencias
* **Gestión de Riesgos:** Identificación, análisis, mitigación
* **Matriz RACI:** Responsabilidades del equipo
* **Seguimiento:** Reportes de avance, métricas, KPIs
* **Actas de Reunión:** Decisiones, acuerdos, seguimientos

Artefactos Típicos
==================

* Plan de proyecto
* Cronograma Gantt
* Registro de riesgos
* Matriz de responsabilidades
* Reportes de estado
* Actas de comité

Prefijos
========

Los artefactos de este subdominio usan el prefijo **PM_** (Project Management).

Ejemplo: ``PM_001_Plan_Proyecto.rst``

.. note::
   Contenido en desarrollo. La documentación de gestión se actualizará 
   conforme avance el proyecto.
