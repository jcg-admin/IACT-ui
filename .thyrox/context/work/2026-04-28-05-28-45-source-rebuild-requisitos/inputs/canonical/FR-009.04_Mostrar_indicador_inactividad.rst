FR-009.04: Mostrar indicador de inactividad
===========================================

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE mostrar un indicador visual claro del estado de cada
   usuario CUANDO se presenta la lista (BR_003).

**Descripción:**

   Indicadores de estado:
   
   **Usuario ACTIVE:**
   
   - Badge verde "Activo"
   - Fila con fondo normal
   - Todas las acciones disponibles
   
   **Usuario INACTIVE:**
   
   - Badge rojo "Inactivo"
   - Fila con fondo gris atenuado
   - Acciones limitadas (solo ver detalle, reactivar)
   - Tooltip con fecha y motivo de baja
   
   **Información Adicional:**
   
   - Último acceso con indicador de tiempo relativo
   - "Hace 2 horas", "Hace 3 días", "Nunca"
   - Alerta si último acceso > 30 días (usuario potencialmente abandonado)

----

3. Criterio de Aceptación
-------------------------

::

   DADO lista de usuarios con diferentes estados
   CUANDO se muestra la lista
   ENTONCES cada usuario tiene indicador visual de su estado
   
   Escenario 1: Usuario activo
   DADO usuario con status = ACTIVE
   CUANDO se muestra en lista
   ENTONCES tiene badge verde "Activo"
   Y la fila tiene estilo normal
   
   Escenario 2: Usuario inactivo
   DADO usuario con status = INACTIVE
   CUANDO se muestra en lista
   ENTONCES tiene badge rojo "Inactivo"
   Y la fila tiene fondo gris
   Y al hover muestra tooltip con motivo de baja
   
   Escenario 3: Alerta de inactividad prolongada
   DADO usuario activo sin login en 45 días
   CUANDO se muestra en lista
   ENTONCES aparece icono de advertencia
   Y tooltip indica "Sin actividad hace 45 días"
   
   Escenario 4: Primer acceso pendiente
   DADO usuario recién creado sin ningún login
   CUANDO se muestra en lista
   ENTONCES último acceso muestra "Nunca"
   Y tiene indicador "Pendiente primer acceso"

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:**
  - BR_003: Visibilidad de estado de usuarios
  
- **CNST aplicables:** Ninguna específica

**Accesibilidad:**

Los indicadores deben ser distinguibles no solo por color sino
también por forma/texto para usuarios con daltonismo.
