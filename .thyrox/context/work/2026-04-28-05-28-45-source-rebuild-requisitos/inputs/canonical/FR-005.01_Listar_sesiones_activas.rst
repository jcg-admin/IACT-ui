2. Especificación
-----------------

**Declaración:**

   El sistema DEBE mostrar un listado de todas las sesiones activas
   CUANDO un administrador de seguridad accede a la gestión de sesiones.

**Descripción:**

   El sistema obtiene y presenta:
   
   **Datos por Sesión:**
   
   - Username del usuario
   - Nombre completo del usuario
   - IP de origen
   - User Agent (navegador/dispositivo)
   - Fecha/hora de inicio de sesión
   - Fecha/hora de última actividad
   - Duración de la sesión
   - Estado (ACTIVE)
   
   **Funcionalidades del Listado:**
   
   - Paginación (20 sesiones por página)
   - Ordenamiento por: usuario, inicio, última actividad
   - Filtro por: usuario, rango de fechas, IP
   - Búsqueda por username
   - Actualización automática cada 30 segundos

----

3. Criterio de Aceptación
-------------------------

::

   DADO un admin de seguridad con AGR-008
   CUANDO accede a "Gestionar Sesiones"
   ENTONCES ve listado de todas las sesiones activas
   
   Escenario 1: Listado inicial
   DADO admin en pantalla de sesiones
   CUANDO carga la vista
   ENTONCES se muestran las sesiones ordenadas por última actividad DESC
   Y se muestra contador total de sesiones activas
   
   Escenario 2: Paginación
   DADO más de 20 sesiones activas
   CUANDO se navega entre páginas
   ENTONCES se muestran 20 sesiones por página
   Y se mantienen los filtros aplicados
   
   Escenario 3: Filtro por usuario
   DADO filtro por username = "juan"
   CUANDO se aplica el filtro
   ENTONCES se muestran solo sesiones de usuarios que contienen "juan"
   
   Escenario 4: Auto-refresh
   DADO listado de sesiones visible
   CUANDO pasan 30 segundos
   ENTONCES el listado se actualiza automáticamente
   Y se preserva la posición de scroll
