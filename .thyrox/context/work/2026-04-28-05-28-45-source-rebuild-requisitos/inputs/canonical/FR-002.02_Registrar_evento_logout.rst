2. Especificación
-----------------

**Declaración:**

   El sistema DEBE registrar un evento de auditoría inmutable CUANDO
   un usuario cierra su sesión exitosamente (BR_008).

**Descripción:**

   El sistema crea un registro en la tabla de auditoría con:
   
   **Datos del Evento:**
   
   - ``event_type``: 'LOGOUT'
   - ``user_id``: ID del usuario
   - ``username``: username del usuario
   - ``timestamp``: fecha/hora exacta (UTC)
   - ``ip_address``: IP del cliente
   - ``session_id``: jti del token cerrado
   - ``session_duration``: duración de la sesión en segundos
   - ``logout_type``: 'VOLUNTARY' | 'FORCED' | 'EXPIRED'

----

3. Criterio de Aceptación
-------------------------

::

   DADO un cierre de sesión exitoso
   CUANDO se invalida el token
   ENTONCES se registra evento en tabla de auditoría
   
   Escenario 1: Logout voluntario
   DADO usuario que cierra sesión manualmente
   CUANDO se completa el cierre
   ENTONCES existe registro con event_type = 'LOGOUT'
   Y logout_type = 'VOLUNTARY'
   Y session_duration contiene duración real
   
   Escenario 2: Logout forzado por admin
   DADO admin que fuerza cierre de sesión de otro usuario
   CUANDO se invalida la sesión
   ENTONCES logout_type = 'FORCED'
   Y se registra admin_user_id que ejecutó la acción
   
   Escenario 3: Cálculo de duración
   DADO sesión iniciada a las 10:00 y cerrada a las 12:30
   CUANDO se registra el logout
   ENTONCES session_duration = 9000 (segundos)

----
