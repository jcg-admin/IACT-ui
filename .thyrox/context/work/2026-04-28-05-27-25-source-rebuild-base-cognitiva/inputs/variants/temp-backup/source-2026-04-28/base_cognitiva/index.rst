==============
Base Cognitiva
==============

Propósito del Dominio
=====================

La **Base Cognitiva** establece el fundamento semántico, conceptual y estructural del proyecto IACT.

Este dominio responde a la pregunta fundamental: **"¿Qué significan los conceptos que usamos?"**

Contenido
=========

La Base Cognitiva proporciona:

* **Lenguaje común:** Vocabulario oficial y términos técnicos del proyecto
* **Base semántica:** Definiciones precisas que eliminan ambigüedad
* **Fundamento teórico:** Marco conceptual que sustenta el modelo de análisis
* **Trazabilidad:** Base para la interpretación correcta de requisitos
