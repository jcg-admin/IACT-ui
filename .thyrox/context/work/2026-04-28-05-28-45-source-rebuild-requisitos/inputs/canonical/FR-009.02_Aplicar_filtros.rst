2. Especificación
-----------------

**Declaración:**

   El sistema DEBE permitir filtrar la lista de usuarios por múltiples
   criterios CUANDO el actor aplica filtros en la interfaz.

**Descripción:**

   Filtros disponibles:
   
   **Filtro por Estado:**
   
   - Todos (por defecto)
   - Solo Activos
   - Solo Inactivos
   
   **Filtro por Búsqueda de Texto:**
   
   - Busca en: username, nombre completo, email
   - Búsqueda parcial (contains)
   - Case insensitive
   
   **Filtro por Rol:**
   
   - Dropdown con roles disponibles
   - Muestra usuarios que tengan el rol seleccionado
   
   **Combinación de Filtros:**
   
   Los filtros se combinan con AND lógico.

----

3. Criterio de Aceptación
-------------------------

::

   DADO lista de usuarios visible
   CUANDO el actor aplica filtros
   ENTONCES la lista se actualiza mostrando solo coincidencias
   
   Escenario 1: Filtro por estado
   DADO filtro estado = "Inactivos"
   CUANDO se aplica
   ENTONCES solo se muestran usuarios con status = INACTIVE
   
   Escenario 2: Búsqueda por texto
   DADO texto de búsqueda = "juan"
   CUANDO se aplica
   ENTONCES se muestran usuarios donde username, nombre o email contienen "juan"
   
   Escenario 3: Filtros combinados
   DADO estado = "Activos" Y búsqueda = "perez"
   CUANDO se aplican ambos
   ENTONCES se muestran usuarios activos cuyo nombre contiene "perez"
   
   Escenario 4: Sin resultados
   DADO filtros que no coinciden con ningún usuario
   CUANDO se aplican
   ENTONCES se muestra "No se encontraron usuarios"
   Y se ofrece opción de limpiar filtros
   
   Escenario 5: Limpiar filtros
   DADO filtros aplicados
   CUANDO se presiona "Limpiar"
   ENTONCES se remueven todos los filtros
   Y se muestra lista completa

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:** Ninguna específica
  
- **CNST aplicables:** Ninguna específica

**UX:**

- Filtros aplicados visibles como "chips" removibles
- Actualización en tiempo real (debounce 300ms para búsqueda)
- Mantener filtros al paginar
