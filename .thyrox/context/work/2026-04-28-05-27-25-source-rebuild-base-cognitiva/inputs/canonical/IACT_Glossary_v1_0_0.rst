=============================
Glosario IACT - Versión 1.0.0
=============================

Términos del Proyecto
=====================

Este glosario contiene las definiciones oficiales de los términos técnicos y de negocio 
utilizados en el proyecto IACT.

A
-

**Analytics**
    Proceso de análisis de datos para obtener insights y métricas de negocio.

**API REST**
    Interfaz de programación de aplicaciones que utiliza el protocolo HTTP para 
    comunicación entre sistemas.

D
-

**Dashboard**
    Interfaz visual que presenta métricas y KPIs de manera consolidada para facilitar 
    la toma de decisiones.

**Django REST Framework**
    Framework de Python para construir APIs REST de manera rápida y robusta.

E
-

**ETL**
    Extract, Transform, Load. Proceso de extracción de datos desde una fuente, 
    transformación según reglas de negocio, y carga en un destino analítico.

M
-

**MySQL**
    Sistema de gestión de bases de datos relacional utilizado como fuente operativa 
    en el proyecto IACT.

P
-

**PostgreSQL**
    Sistema de gestión de bases de datos relacional utilizado como base de datos 
    analítica en el proyecto IACT.

R
-

**RBAC**
    Role-Based Access Control. Control de acceso basado en roles funcionales del sistema.

**React**
    Biblioteca de JavaScript para construir interfaces de usuario interactivas.

**Rol Funcional**
    Capacidad técnica del sistema (ej: REPORTS_VIEWER) independiente de puestos 
    organizacionales.

.. note::
   Este glosario está en desarrollo y se actualizará conforme se identifiquen 
   nuevos términos técnicos del proyecto.
