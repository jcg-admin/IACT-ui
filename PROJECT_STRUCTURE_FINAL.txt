FLUJOS DE TRABAJO
═════════════════════════════════════════════════════════════════════════════

DESARROLLO:
1. npm install
2. npm start (dev server en :3000)
3. npm test (tests en watch mode)
4. Editar componentes en src/
5. Ver cambios en vivo

TESTING:
1. npm test (watch mode)
2. npm test -- --coverage (coverage report)
3. npm test -- --clearCache (clear Jest cache)

BUILD:
1. npm run build (producción)
2. npm run build:analyze (analizar bundle)
3. npm start (servir build local)

DEPLOYMENT:
1. npm run build
2. Desplegar dist/ a hosting
3. Configurar env vars
4. Setup monitoring/analytics
