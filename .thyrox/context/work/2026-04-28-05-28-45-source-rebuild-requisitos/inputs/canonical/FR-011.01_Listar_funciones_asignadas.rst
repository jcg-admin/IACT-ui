FR-011.01: Listar funciones asignadas al usuario
================================================

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE mostrar todas las funciones asignadas al usuario
   con su origen y metadata CUANDO el admin accede a la revocación.

**Descripción:**

   Para cada función asignada mostrar:
   
   **Información de la Función:**
   
   - Código (AUT-xxx, USR-xxx, etc.)
   - Nombre descriptivo
   - Módulo al que pertenece
   - Descripción breve
   
   **Metadata de Asignación:**
   
   - Fecha de asignación
   - Quién la asignó
   - Origen: Directa | vía Agrupador (indicar cuál)
   - Vigencia: Indefinida | Hasta [fecha]
   
   **Indicadores Especiales:**
   
   - Funciones que no se pueden revocar (ej: última función admin)
   - Funciones con dependencias

----

3. Criterio de Aceptación
-------------------------

::

   DADO un admin en pantalla de revocación
   CUANDO se carga la vista para un usuario
   ENTONCES ve todas las funciones asignadas con su metadata
   
   Escenario 1: Lista completa
   DADO usuario con 5 funciones asignadas
   CUANDO se carga la pantalla
   ENTONCES se muestran las 5 funciones
   Y cada una tiene su metadata visible
   
   Escenario 2: Distinción de origen
   DADO función asignada vía AGR-003
   CUANDO se muestra en lista
   ENTONCES indica "vía AGR-003"
   Y tiene icono de agrupador
   
   Escenario 3: Función no revocable
   DADO último usuario con ACC-001
   CUANDO se muestra ACC-001 en su lista
   ENTONCES está deshabilitada para selección
   Y tooltip indica "No se puede revocar: único admin con esta función"
   
   Escenario 4: Selección múltiple
   DADO lista de funciones visible
   CUANDO admin selecciona varias
   ENTONCES se habilita botón "Revocar seleccionadas"

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:**
  - BR_006: RBAC Flat NIST
  
- **CNST aplicables:** Ninguna específica

**Protección:**

No permitir revocar la última función administrativa del sistema
para evitar bloqueo de acceso.
