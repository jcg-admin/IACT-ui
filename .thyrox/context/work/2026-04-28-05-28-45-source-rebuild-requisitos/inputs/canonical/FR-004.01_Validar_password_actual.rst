FR-004.01: Validar password actual
==================================

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE validar que el password actual proporcionado sea
   correcto CUANDO el usuario solicita cambiar su password.

**Descripción:**

   El proceso de validación:
   
   1. Recibe password actual del formulario
   2. Obtiene hash almacenado del usuario autenticado
   3. Compara usando bcrypt.verify()
   4. Si coincide, permite continuar al siguiente paso
   5. Si no coincide, muestra error y permite reintentar
   
   **Seguridad:**
   
   Esta validación previene que un atacante con acceso a una sesión
   activa pueda cambiar el password sin conocer el actual.

----

3. Criterio de Aceptación
-------------------------

::

   DADO un usuario autenticado en pantalla de cambio de password
   CUANDO ingresa su password actual
   ENTONCES el sistema valida que sea correcto
   
   Escenario 1: Password actual correcto
   DADO password actual válido
   CUANDO se envía el formulario
   ENTONCES la validación pasa
   Y se habilita el siguiente paso
   
   Escenario 2: Password actual incorrecto
   DADO password actual inválido
   CUANDO se envía el formulario
   ENTONCES se muestra "Password actual incorrecto"
   Y el formulario permanece en el mismo paso
   Y se permite reintentar
   
   Escenario 3: Múltiples intentos fallidos
   DADO 5 intentos fallidos consecutivos
   CUANDO se intenta nuevamente
   ENTONCES se bloquea temporalmente la operación
   Y se cierra la sesión por seguridad

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:** Ninguna específica
  
- **CNST aplicables:**
  - CNST-005: Seguridad DRF

**Límites:**

- Máximo 5 intentos fallidos antes de cierre forzado de sesión
- Cada intento fallido se registra en auditoría
- Tiempo de respuesta constante para prevenir timing attacks
