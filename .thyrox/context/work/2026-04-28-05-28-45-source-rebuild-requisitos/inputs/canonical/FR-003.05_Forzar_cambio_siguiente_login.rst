2. Especificación
-----------------

**Declaración:**

   El sistema DEBE marcar la cuenta para forzar cambio de password
   CUANDO se genera un password temporal, obligando al usuario a
   establecer un nuevo password en su siguiente login exitoso.

**Descripción:**

   El sistema implementa el forzado de cambio:
   
   1. Actualiza campo ``must_change_password = true`` en tabla users
   2. Registra timestamp de la solicitud de recuperación
   3. En el siguiente login exitoso con password temporal:
      - Redirecciona a pantalla de cambio de password
      - No permite acceso a otras funciones hasta cambiar
      - Muestra mensaje explicativo
   4. Después de cambiar, ``must_change_password = false``

----

3. Criterio de Aceptación
-------------------------

::

   DADO un password temporal generado
   CUANDO el sistema marca la cuenta
   ENTONCES el siguiente login fuerza cambio de password
   
   Escenario 1: Marcado de cuenta
   DADO password temporal recién generado
   CUANDO se completa el proceso de recuperación
   ENTONCES users.must_change_password = true
   Y users.password_changed_at = null
   
   Escenario 2: Login con password temporal
   DADO usuario con must_change_password = true
   CUANDO hace login exitoso
   ENTONCES es redirigido a /change-password
   Y NO puede navegar a otras páginas
   Y ve mensaje "Debe cambiar su password temporal"
   
   Escenario 3: Después de cambiar password
   DADO usuario que cambió password exitosamente
   CUANDO se guarda el nuevo password
   ENTONCES must_change_password = false
   Y password_changed_at = NOW()
   Y es redirigido a dashboard
   
   Escenario 4: Intento de evadir cambio
   DADO usuario con must_change_password = true
   CUANDO intenta acceder a /dashboard directamente
   ENTONCES es redirigido a /change-password
   Y no puede evadir el cambio obligatorio
