FR-008.03: Invalidar sesiones del usuario dado de baja
======================================================

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE invalidar inmediatamente todas las sesiones activas
   del usuario CUANDO se completa la baja lógica.

**Descripción:**

   El proceso de invalidación:
   
   1. Identifica todas las sesiones activas del usuario
   2. Actualiza status a 'USER_DEACTIVATED' en user_sessions
   3. Agrega todos los tokens a blacklist de Redis
   4. El usuario recibe 401 en cualquier request posterior
   5. Se muestra mensaje "Su cuenta ha sido desactivada"
   
   **Efecto Inmediato:**
   
   Si el usuario está usando el sistema en el momento de la baja,
   será desconectado inmediatamente al siguiente request.

----

3. Criterio de Aceptación
-------------------------

::

   DADO un usuario dado de baja exitosamente
   CUANDO se completa el cambio de estado
   ENTONCES todas sus sesiones se invalidan inmediatamente
   
   Escenario 1: Sesiones invalidadas
   DADO usuario con 2 sesiones activas
   CUANDO se ejecuta la baja
   ENTONCES ambas sesiones cambian a status = 'USER_DEACTIVATED'
   Y ambos tokens se agregan a blacklist
   
   Escenario 2: Desconexión inmediata
   DADO usuario conectado al momento de la baja
   CUANDO hace siguiente request
   ENTONCES recibe HTTP 401 Unauthorized
   Y mensaje = "Su cuenta ha sido desactivada"
   
   Escenario 3: Sin sesiones activas
   DADO usuario sin sesiones activas
   CUANDO se ejecuta la baja
   ENTONCES el proceso continúa normalmente
   Y no hay sesiones que invalidar
   
   Escenario 4: Auditoría de invalidación
   DADO sesiones invalidadas por baja
   CUANDO se registra auditoría
   ENTONCES event_type = 'SESSIONS_INVALIDATED'
   Y reason = 'USER_DEACTIVATED'

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:** Ninguna específica
  
- **CNST aplicables:**
  - CNST-002: Gestión de sesiones en BD

**Transacción Atómica:**

La invalidación de sesiones debe ser parte de la misma transacción
que el cambio de estado. Si falla una, falla todo.
