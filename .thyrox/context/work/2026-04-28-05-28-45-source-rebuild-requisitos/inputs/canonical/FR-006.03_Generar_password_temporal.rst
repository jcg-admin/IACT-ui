FR-006.03: Generar password temporal
====================================

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE generar un password temporal seguro y mostrarlo en
   pantalla al administrador CUANDO se crea un nuevo usuario (BR_004).

**Descripción:**

   El proceso de generación:
   
   1. Genera password aleatorio criptográficamente seguro
   2. Características: 12 caracteres, alfanuméricos sin ambiguos
   3. Hashea con bcrypt (cost=12) para almacenamiento
   4. Marca usuario con ``must_change_password = true``
   5. Muestra password en pantalla (única vez)
   6. NO envía por email (BR_004: comunicaciones internas)
   
   **Responsabilidad del Admin:**
   
   El administrador debe comunicar el password temporal al usuario
   de forma segura (presencial o canal interno seguro).

----

3. Criterio de Aceptación
-------------------------

::

   DADO validaciones de usuario exitosas
   CUANDO el sistema genera password temporal
   ENTONCES se crea password seguro y se muestra una vez
   
   Escenario 1: Generación exitosa
   DADO usuario nuevo validado
   CUANDO se genera password
   ENTONCES password tiene 12 caracteres
   Y contiene mayúsculas, minúsculas y números
   Y se almacena hasheado en BD
   
   Escenario 2: Visualización única
   DADO password temporal generado
   CUANDO se muestra al admin
   ENTONCES aparece en modal/sección destacada
   Y hay advertencia "Anote este password, no se mostrará de nuevo"
   Y hay botón para copiar al portapapeles
   
   Escenario 3: Forzar cambio
   DADO usuario creado con password temporal
   CUANDO intenta su primer login
   ENTONCES es obligado a cambiar password (FR-003.05)

----
