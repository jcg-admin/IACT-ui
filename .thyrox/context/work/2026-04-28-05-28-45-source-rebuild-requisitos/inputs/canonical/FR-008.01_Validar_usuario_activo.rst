=============================================
FR-008.01: Validar que el usuario está activo
=============================================

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE validar que el usuario tiene estado ACTIVE CUANDO
   el administrador intenta dar de baja a un usuario.

**Descripción:**

   Validaciones previas a la baja:
   
   1. Usuario existe en el sistema
   2. Estado actual es 'ACTIVE'
   3. No es el propio usuario ejecutando la acción
   4. No es el último administrador del sistema
   
   **Restricciones de Seguridad:**
   
   - Un administrador no puede darse de baja a sí mismo
   - No se puede dar de baja al último usuario con rol admin_sistema

----

3. Criterio de Aceptación
-------------------------

::

   DADO un administrador intentando dar de baja a un usuario
   CUANDO selecciona la opción "Dar de Baja"
   ENTONCES el sistema valida el estado del usuario
   
   Escenario 1: Usuario activo - permitido
   DADO usuario con status = 'ACTIVE'
   CUANDO se intenta dar de baja
   ENTONCES se permite continuar con el proceso
   
   Escenario 2: Usuario ya inactivo
   DADO usuario con status = 'INACTIVE'
   CUANDO se intenta dar de baja
   ENTONCES se muestra "El usuario ya está inactivo"
   Y no se permite la operación
   
   Escenario 3: Auto-baja impedida
   DADO admin intentando darse de baja a sí mismo
   CUANDO selecciona "Dar de Baja"
   ENTONCES se muestra "No puede dar de baja su propia cuenta"
   
   Escenario 4: Último admin protegido
   DADO único usuario con rol admin_sistema
   CUANDO se intenta dar de baja
   ENTONCES se muestra "No se puede dar de baja al último administrador"

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:** Ninguna específica
  
- **CNST aplicables:**
  - CNST-010: Segregación de funciones

**Protección del Sistema:**

El sistema debe garantizar que siempre exista al menos un usuario
con capacidad de administración para evitar bloqueo total.
