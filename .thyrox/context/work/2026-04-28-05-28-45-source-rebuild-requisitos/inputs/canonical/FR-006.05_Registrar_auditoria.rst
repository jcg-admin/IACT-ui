FR-006.05: Registrar evento de creación en auditoría
====================================================

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE registrar un evento de auditoría inmutable CUANDO
   se crea exitosamente un nuevo usuario en el sistema.

**Descripción:**

   El registro de auditoría incluye:
   
   **Datos del Evento:**
   
   - ``event_type``: 'USER_CREATED'
   - ``actor_user_id``: ID del admin que creó
   - ``target_user_id``: ID del usuario creado
   - ``timestamp``: Fecha/hora exacta (UTC)
   - ``ip_address``: IP del admin
   - ``details``: JSON con datos no sensibles
   
   **Contenido de Details:**
   
   .. code-block:: json
   
      {
        "username": "nuevo.usuario",
        "full_name": "Nombre Completo",
        "email": "usuario@empresa.com",
        "initial_status": "ACTIVE"
      }
   
   **Datos Excluidos (seguridad):**
   
   - Password temporal (nunca en logs)
   - Respuesta de seguridad

----

3. Criterio de Aceptación
-------------------------

::

   DADO un usuario creado exitosamente
   CUANDO se completa la transacción
   ENTONCES se registra evento en auditoría
   
   Escenario 1: Registro completo
   DADO creación exitosa de usuario
   CUANDO se registra auditoría
   ENTONCES existe registro con event_type = 'USER_CREATED'
   Y actor_user_id = ID del admin
   Y target_user_id = ID del nuevo usuario
   
   Escenario 2: Datos sensibles excluidos
   DADO registro de auditoría
   CUANDO se consulta details
   ENTONCES NO contiene password
   Y NO contiene security_answer
   
   Escenario 3: Inmutabilidad
   DADO registro de auditoría creado
   CUANDO se intenta modificar
   ENTONCES la operación es rechazada (CNST-009)

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:**
  - BR_008: Auditoría obligatoria
  
- **CNST aplicables:**
  - CNST-009: Logging y auditoría inmutable
  - CNST-010: Clasificación de datos (excluir PII sensible)

**Transacción:**

El registro de auditoría es parte de la misma transacción que la
creación del usuario. Si falla la auditoría, se revierte todo.
