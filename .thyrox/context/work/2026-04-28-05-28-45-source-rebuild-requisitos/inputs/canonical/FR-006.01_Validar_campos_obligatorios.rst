FR-006.01: Validar campos obligatorios
======================================

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE validar que todos los campos obligatorios estén
   completos y con formato correcto CUANDO el administrador envía
   el formulario de creación de usuario.

**Descripción:**

   Campos obligatorios y sus validaciones:
   
   **Username:**
   
   - Obligatorio
   - 3-50 caracteres
   - Solo alfanuméricos, guion bajo, punto
   - No inicia con número
   
   **Nombre completo:**
   
   - Obligatorio
   - 2-100 caracteres
   - Letras, espacios, tildes permitidos
   
   **Email interno:**
   
   - Obligatorio
   - Formato email válido
   - Dominio debe ser @empresa.com (configurable)
   
   **Pregunta de seguridad:**
   
   - Obligatorio
   - Selección de lista predefinida
   
   **Respuesta de seguridad:**
   
   - Obligatorio
   - Mínimo 3 caracteres

----

3. Criterio de Aceptación
-------------------------

::

   DADO un administrador en formulario de crear usuario
   CUANDO envía el formulario
   ENTONCES el sistema valida todos los campos obligatorios
   
   Escenario 1: Todos los campos válidos
   DADO formulario con todos los campos correctos
   CUANDO se envía
   ENTONCES la validación pasa y continúa el proceso
   
   Escenario 2: Campo faltante
   DADO formulario sin nombre completo
   CUANDO se envía
   ENTONCES se muestra "El campo Nombre es obligatorio"
   Y el foco va al campo faltante
   
   Escenario 3: Formato inválido de email
   DADO email = "usuario@otrodominio.com"
   CUANDO se envía
   ENTONCES se muestra "Email debe ser del dominio @empresa.com"
   
   Escenario 4: Username con caracteres inválidos
   DADO username = "juan@perez"
   CUANDO se envía
   ENTONCES se muestra "Username solo permite letras, números, _ y ."
