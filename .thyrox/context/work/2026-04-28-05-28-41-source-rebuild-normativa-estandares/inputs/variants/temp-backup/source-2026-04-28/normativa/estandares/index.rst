.. _estandares:

==========
Estándares
==========

Propósito
=========

Este subdominio define los **estándares de documentación** del proyecto IACT, 
estableciendo formatos, notaciones, plantillas y convenciones de estilo.

Contenido
=========

Los estándares incluyen:

* Nomenclatura documental (prefijos, convenciones)
* Estructura de documentos
* Plantillas reutilizables
* Guías de estilo

.. note::
   Contenido en desarrollo. Los estándares se definirán conforme se establezcan 
   las convenciones del proyecto.
