2. Especificación
-----------------

**Declaración:**

   El sistema DEBE mostrar el catálogo de funciones disponibles junto
   con las funciones ya asignadas al usuario CUANDO el administrador
   accede a la pantalla de asignación.

**Descripción:**

   El sistema presenta dos listas:
   
   **Funciones Ya Asignadas:**
   
   - Funciones directas (asignadas individualmente)
   - Funciones vía agrupador (indicando qué agrupador)
   - Fecha de asignación
   - Quién asignó
   
   **Funciones Disponibles:**
   
   - Todas las funciones del catálogo RBAC
   - Agrupadas por módulo (MOD_Auth, MOD_Users, etc.)
   - Código, nombre y descripción
   - Indicador si ya está asignada
   - Indicador de conflicto SoD potencial
   
   **Agrupadores Disponibles:**
   
   - Lista de AGR-00x disponibles
   - Funciones que incluye cada agrupador

----

3. Criterio de Aceptación
-------------------------

::

   DADO un admin en pantalla de asignación de funciones
   CUANDO carga la vista para un usuario
   ENTONCES ve funciones actuales y disponibles
   
   Escenario 1: Vista inicial
   DADO usuario "juan.perez" con 3 funciones asignadas
   CUANDO se carga la pantalla
   ENTONCES se muestran las 3 funciones en sección "Asignadas"
   Y se muestra catálogo completo en sección "Disponibles"
   
   Escenario 2: Funciones por agrupador
   DADO usuario con AGR-003 asignado
   CUANDO se listan funciones asignadas
   ENTONCES las funciones del AGR-003 aparecen con badge "vía AGR-003"
   
   Escenario 3: Indicador de conflicto SoD
   DADO función ACC-005 en conflicto SoD con función ya asignada
   CUANDO se lista en disponibles
   ENTONCES aparece icono de advertencia
   Y tooltip indica "Conflicto SoD con ACC-002"
   
   Escenario 4: Filtro por módulo
   DADO catálogo de funciones visible
   CUANDO se filtra por "MOD_Reports"
   ENTONCES solo se muestran funciones de ese módulo

----
