2. Especificación
-----------------

**Declaración:**

   El sistema DEBE permitir cerrar una sesión específica CUANDO el
   administrador de seguridad lo solicita y confirma la acción.

**Descripción:**

   El proceso de cierre individual:
   
   1. Admin selecciona sesión a cerrar
   2. Sistema solicita confirmación con datos de la sesión
   3. Admin confirma la acción
   4. Sistema actualiza status en user_sessions a 'FORCED_LOGOUT'
   5. Sistema agrega token a blacklist de Redis
   6. Sistema registra evento en auditoría con admin que ejecutó
   7. Sistema actualiza listado de sesiones
   8. Usuario afectado recibe 401 en siguiente request
   
   **Información en Confirmación:**
   
   - Usuario afectado
   - IP de la sesión
   - Tiempo activa
   - Advertencia de impacto

----

3. Criterio de Aceptación
-------------------------

::

   DADO admin con sesión seleccionada
   CUANDO solicita cerrar la sesión
   ENTONCES se invalida tras confirmación
   
   Escenario 1: Cierre exitoso
   DADO sesión activa de otro usuario
   CUANDO admin confirma cierre
   ENTONCES status cambia a 'FORCED_LOGOUT'
   Y token se agrega a blacklist
   Y se registra en auditoría
   
   Escenario 2: Cancelación
   DADO solicitud de cierre
   CUANDO admin cancela confirmación
   ENTONCES la sesión permanece activa
   Y no se registra ningún cambio
   
   Escenario 3: Cierre de propia sesión impedido
   DADO admin intentando cerrar su propia sesión actual
   CUANDO solicita el cierre
   ENTONCES se muestra "No puede cerrar su sesión actual desde aquí"
   
   Escenario 4: Registro de auditoría
   DADO cierre de sesión exitoso
   CUANDO se completa
   ENTONCES auditoría contiene:
      - event_type = 'SESSION_FORCED_LOGOUT'
      - admin_user_id = ID del admin
      - target_user_id = ID del usuario afectado
      - target_session_id = jti cerrado

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:** Ninguna específica
  
- **CNST aplicables:**
  - CNST-002: Gestión de sesiones
  - CNST-009: Auditoría obligatoria

**Restricciones:**

- No se puede cerrar la propia sesión actual
- Se requiere confirmación explícita
- Acción irreversible
