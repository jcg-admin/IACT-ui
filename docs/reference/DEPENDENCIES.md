# Project Dependencies

Complete list of npm dependencies.

## Core Dependencies

### React Ecosystem
- **react** 18.2+ - UI framework
- **react-dom** 18.2+ - DOM rendering
- **react-router-dom** 6.4+ - Client routing

### State Management
- **@reduxjs/toolkit** 1.9+ - Redux toolkit
- **react-redux** 8.1+ - React-Redux bindings
- **redux** 4.2+ - Redux core

### Bundling & Transpilation
- **webpack** 5.x - Module bundler
- **webpack-cli** 5.x - Webpack CLI
- **babel** 7.x - JavaScript transpiler
- **@babel/preset-react** - React JSX preset
- **sass** 7.1+ - SCSS compiler
- **style-loader** - CSS loader
- **css-loader** - CSS modules support
- **sass-loader** - SCSS loader

### Development Dependencies
- **jest** 29.7+ - Testing framework
- **@testing-library/react** 14+ - Component testing
- **@testing-library/jest-dom** 6+ - Jest matchers
- **eslint** 8.x - Code linting
- **prettier** 3.x - Code formatting

## Installation

```bash
npm install
```

## Scripts

```bash
npm start           # Start dev server
npm test            # Run tests
npm run build       # Build for production
npm run lint        # Run ESLint
npm run format      # Format code
```
