FR-007.02: Validar campos modificados
=====================================

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE validar únicamente los campos que fueron modificados
   CUANDO el administrador envía el formulario de edición.

**Descripción:**

   El sistema realiza validación selectiva:
   
   1. Detecta qué campos fueron modificados (diff con valores originales)
   2. Aplica validaciones solo a campos cambiados
   3. Valida formato y reglas de negocio específicas
   
   **Validaciones por Campo:**
   
   - **Email**: Si cambió, verificar formato y dominio
   - **Nombre**: Si cambió, verificar longitud y caracteres
   - **Estado**: Si cambió a INACTIVE, requerir motivo
   - **Pregunta seguridad**: Si cambió, validar selección
   - **Respuesta seguridad**: Si se ingresó, validar mínimo 3 caracteres

----

3. Criterio de Aceptación
-------------------------

::

   DADO un formulario de edición con cambios
   CUANDO el administrador envía
   ENTONCES solo se validan los campos modificados
   
   Escenario 1: Solo nombre modificado
   DADO solo campo nombre cambiado
   CUANDO se valida
   ENTONCES solo se ejecuta validación de nombre
   Y otros campos no se re-validan
   
   Escenario 2: Cambio de estado a INACTIVE
   DADO status cambiado de ACTIVE a INACTIVE
   CUANDO se valida
   ENTONCES se requiere campo "motivo" obligatorio
   Y motivo debe tener mínimo 10 caracteres
   
   Escenario 3: Sin cambios
   DADO formulario enviado sin modificaciones
   CUANDO se procesa
   ENTONCES se muestra "No hay cambios para guardar"
   Y no se ejecuta actualización
   
   Escenario 4: Email duplicado
   DADO email cambiado a uno que ya existe
   CUANDO se valida
   ENTONCES se muestra "Email ya está en uso por otro usuario"

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:** Ninguna específica
  
- **CNST aplicables:**
  - CNST-005: Seguridad (sanitización)

**Optimización:**

La validación selectiva reduce carga en servidor y mejora UX
al no mostrar errores en campos no modificados.
