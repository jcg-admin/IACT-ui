FR-010.03: Crear asignación usuario-función
===========================================

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE crear registros de asignación en la tabla
   user_functions CUANDO la validación SoD ha sido exitosa y el
   admin confirma la asignación.

**Descripción:**

   Proceso de creación:
   
   1. Para cada función seleccionada, crear registro
   2. Si se seleccionó agrupador, crear registro con referencia al AGR
   3. Registrar metadata de la asignación
   4. Registrar evento en auditoría
   
   **Estructura del Registro:**
   
   .. list-table::
      :widths: 25 20 55
      :header-rows: 1
   
      * - Campo
        - Tipo
        - Valor
      * - id
        - UUID
        - Generado
      * - user_id
        - UUID
        - ID del usuario destino
      * - function_code
        - VARCHAR(20)
        - Código de función (AUT-xxx)
      * - grouper_code
        - VARCHAR(20)
        - Código de agrupador (si aplica)
      * - assigned_at
        - TIMESTAMP
        - NOW()
      * - assigned_by
        - UUID
        - ID del admin que asigna
      * - valid_from
        - DATE
        - Fecha inicio vigencia
      * - valid_until
        - DATE
        - Fecha fin (NULL = indefinido)

----

3. Criterio de Aceptación
-------------------------

::

   DADO validación SoD exitosa y confirmación del admin
   CUANDO se crea la asignación
   ENTONCES se registran las funciones en BD y auditoría
   
   Escenario 1: Asignación directa de función
   DADO función ACC-003 seleccionada directamente
   CUANDO se confirma asignación
   ENTONCES existe registro con function_code = 'ACC-003'
   Y grouper_code = NULL
   Y assigned_by = ID del admin actual
   
   Escenario 2: Asignación vía agrupador
   DADO agrupador AGR-003 seleccionado
   CUANDO se confirma asignación
   ENTONCES existe registro por cada función del AGR-003
   Y todos tienen grouper_code = 'AGR-003'
   
   Escenario 3: Asignación temporal
   DADO asignación con fecha de fin
   CUANDO se crea el registro
   ENTONCES valid_until = fecha especificada
   Y la función se revocará automáticamente al vencer
   
   Escenario 4: Auditoría de asignación
   DADO asignación completada
   CUANDO se registra auditoría
   ENTONCES event_type = 'FUNCTION_ASSIGNED'
   Y details contiene funciones asignadas

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:**
  - BR_006: RBAC Flat NIST
  
- **CNST aplicables:**
  - CNST-002: Gestión de datos en BD

**Unicidad:**

Constraint UNIQUE en (user_id, function_code) para evitar
asignaciones duplicadas de la misma función.
