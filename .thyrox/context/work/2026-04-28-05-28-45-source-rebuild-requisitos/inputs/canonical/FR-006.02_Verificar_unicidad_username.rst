FR-006.02: Verificar unicidad de username
=========================================

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE verificar que el username propuesto no exista en la
   base de datos CUANDO se validan los campos del formulario (BR_013).

**Descripción:**

   El proceso de verificación:
   
   1. Normaliza el username (lowercase, trim)
   2. Consulta tabla ``users`` buscando coincidencia exacta
   3. Incluye usuarios activos e inactivos en la búsqueda
   4. Si existe, retorna error y sugiere alternativas
   5. Si no existe, permite continuar
   
   **Verificación en Tiempo Real:**
   
   Opcionalmente, el frontend puede verificar disponibilidad mientras
   el usuario escribe (debounce 500ms) para mejorar UX.

----

3. Criterio de Aceptación
-------------------------

::

   DADO un username propuesto en el formulario
   CUANDO el sistema verifica unicidad
   ENTONCES confirma disponibilidad o indica duplicado
   
   Escenario 1: Username disponible
   DADO username = "nuevo.usuario"
   CUANDO se verifica en BD
   ENTONCES retorna disponible = true
   Y se permite continuar con creación
   
   Escenario 2: Username ya existe (activo)
   DADO username = "juan.perez" que existe con status ACTIVE
   CUANDO se verifica
   ENTONCES se muestra "Username no disponible"
   Y se sugieren alternativas: "juan.perez1", "juan.perez_2"
   
   Escenario 3: Username existe pero inactivo
   DADO username que existe con status INACTIVE
   CUANDO se verifica
   ENTONCES también se rechaza (no se reutilizan usernames)
   Y se muestra "Username no disponible"
   
   Escenario 4: Case insensitive
   DADO username existente = "Juan.Perez"
   CUANDO se intenta crear "juan.perez"
   ENTONCES se rechaza como duplicado

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:**
  - BR_013: Username único en todo el sistema
  
- **CNST aplicables:** Ninguna específica

**Índice de BD:**

La tabla ``users`` debe tener índice único en campo ``username``
normalizado (lowercase) para garantizar unicidad a nivel de BD.
