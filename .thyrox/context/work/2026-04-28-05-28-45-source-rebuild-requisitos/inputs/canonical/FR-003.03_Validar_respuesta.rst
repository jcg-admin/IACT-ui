2. Especificación
-----------------

**Declaración:**

   El sistema DEBE validar que la respuesta proporcionada coincida con
   la respuesta almacenada CUANDO el usuario envía su respuesta a la
   pregunta de seguridad.

**Descripción:**

   El proceso de validación:
   
   1. Recibe respuesta del usuario
   2. Normaliza la respuesta (trim, lowercase)
   3. Compara hash de respuesta normalizada con hash almacenado
   4. Si coincide, procede a generar password temporal
   5. Si no coincide, incrementa contador de intentos
   
   **Normalización de Respuesta:**
   
   - Eliminar espacios al inicio y final (trim)
   - Convertir a minúsculas
   - Eliminar acentos/tildes
   - Ejemplo: " Mi Gato " → "mi gato"

----

3. Criterio de Aceptación
-------------------------

::

   DADO un usuario con pregunta de seguridad mostrada
   CUANDO ingresa respuesta y envía
   ENTONCES el sistema valida contra respuesta almacenada
   
   Escenario 1: Respuesta correcta
   DADO respuesta almacenada = "firulais"
   CUANDO usuario ingresa "Firulais" o " FIRULAIS "
   ENTONCES la validación es exitosa
   Y se procede a generar password temporal
   
   Escenario 2: Respuesta incorrecta - primer intento
   DADO respuesta incorrecta en primer intento
   CUANDO se valida
   ENTONCES se muestra "Respuesta incorrecta"
   Y se actualiza "2 intentos restantes"
   
   Escenario 3: Respuesta incorrecta - tercer intento
   DADO 2 intentos fallidos previos
   CUANDO falla tercer intento
   ENTONCES se bloquea recuperación por 30 minutos
   Y se muestra "Demasiados intentos. Intente en 30 minutos"
   
   Escenario 4: Registro de intentos
   DADO cualquier intento de validación
   CUANDO se procesa
   ENTONCES se registra en auditoría (éxito o fallo)

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:** Ninguna específica
  
- **CNST aplicables:**
  - CNST-005: Seguridad DRF
  - CNST-009: Auditoría (registrar intentos)

**Límites:**

- Máximo 3 intentos por sesión de recuperación
- Bloqueo de 30 minutos tras 3 fallos
- Respuesta hasheada con bcrypt (no almacenada en texto plano)
