2. Especificación
-----------------

**Declaración:**

   El sistema DEBE mostrar información detallada de una sesión específica
   CUANDO el administrador selecciona una sesión del listado.

**Descripción:**

   El detalle de sesión incluye:
   
   **Información del Usuario:**
   
   - User ID
   - Username
   - Nombre completo
   - Email
   - Roles asignados
   - Segmento
   
   **Información de la Sesión:**
   
   - Session ID (jti)
   - Fecha/hora de inicio
   - Fecha/hora de última actividad
   - Duración total
   - IP de origen
   - User Agent completo
   - Geolocalización aproximada (si disponible)
   
   **Historial de Actividad:**
   
   - Últimas 10 acciones realizadas
   - Páginas visitadas
   - Acciones de auditoría relacionadas

----

3. Criterio de Aceptación
-------------------------

::

   DADO admin viendo listado de sesiones
   CUANDO selecciona una sesión específica
   ENTONCES se muestra panel con detalle completo
   
   Escenario 1: Detalle básico
   DADO sesión seleccionada
   CUANDO se abre el detalle
   ENTONCES se muestra toda la información del usuario
   Y se muestra toda la información de la sesión
   
   Escenario 2: Historial de actividad
   DADO detalle de sesión abierto
   CUANDO se ve la sección de actividad
   ENTONCES se muestran las últimas 10 acciones
   Y cada acción tiene timestamp y descripción
   
   Escenario 3: Acciones disponibles
   DADO detalle de sesión visible
   CUANDO el admin revisa las opciones
   ENTONCES ve botón "Cerrar esta sesión"
   Y ve botón "Cerrar todas las sesiones del usuario"

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:** Ninguna específica
  
- **CNST aplicables:**
  - CNST-009: Consulta de auditoría para historial

**Datos Sensibles:**

- El token JWT nunca se muestra completo
- Solo se muestran últimos 8 caracteres del jti
- La IP se puede mostrar completa solo a admin_seguridad
