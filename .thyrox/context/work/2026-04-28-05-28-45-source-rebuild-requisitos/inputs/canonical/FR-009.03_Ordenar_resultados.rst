2. Especificación
-----------------

**Declaración:**

   El sistema DEBE permitir ordenar la lista de usuarios por diferentes
   columnas CUANDO el actor hace clic en el encabezado de columna.

**Descripción:**

   Columnas ordenables:
   
   - Username (ASC/DESC)
   - Nombre completo (ASC/DESC)
   - Estado (Activos primero / Inactivos primero)
   - Último acceso (más reciente / más antiguo)
   - Fecha creación (más reciente / más antiguo)
   
   **Comportamiento:**
   
   - Primer clic: orden ascendente
   - Segundo clic: orden descendente
   - Tercer clic: quita ordenamiento de esa columna
   - Indicador visual de columna y dirección activa
   
   **Orden por Defecto:**
   
   Nombre completo ascendente (A-Z)

----

3. Criterio de Aceptación
-------------------------

::

   DADO lista de usuarios visible
   CUANDO el actor hace clic en encabezado de columna
   ENTONCES la lista se reordena por esa columna
   
   Escenario 1: Ordenar por username
   DADO lista sin ordenamiento específico
   CUANDO se hace clic en columna "Username"
   ENTONCES la lista se ordena por username A-Z
   Y aparece indicador ↑ en la columna
   
   Escenario 2: Invertir orden
   DADO lista ordenada por username ASC
   CUANDO se hace clic nuevamente en "Username"
   ENTONCES la lista se ordena por username Z-A
   Y el indicador cambia a ↓
   
   Escenario 3: Ordenar por último acceso
   DADO clic en columna "Último acceso"
   CUANDO se aplica ordenamiento
   ENTONCES usuarios con acceso más reciente aparecen primero
   
   Escenario 4: Mantener orden al paginar
   DADO lista ordenada por nombre DESC
   CUANDO se navega a página 2
   ENTONCES el ordenamiento se mantiene

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:** Ninguna específica
  
- **CNST aplicables:** Ninguna específica

**Performance:**

Ordenamiento ejecutado en servidor (ORDER BY) para conjuntos
grandes. Índices en columnas frecuentemente ordenadas.
