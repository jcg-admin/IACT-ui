Metadata del Proyecto
=====================

Propósito
---------

Este subdominio contiene la **información de identidad, contexto y clasificación del proyecto IACT (IVR Analytics & Customer Tracking)**.

Define:

- Identidad única e inequívoca del proyecto
- Clasificación de confidencialidad y restricciones de acceso
- Fases del ciclo de vida del desarrollo (SDLC)
- Contexto del modelo documental IACT
- Estructura organizativa de la documentación

Audiencia
---------

- Project Management Office (PMO)
- Arquitectos de Documentación
- Nuevos miembros del equipo (onboarding)
- Auditores y stakeholders externos

Estado
------

**Subdominio:** PRIVADO (prefijo ``_``)

**Estado:** CONGELADO (estructura plana, estable)

**Motivo:** Información de contexto interno, metadatos críticos para gobernanza y auditoría.

Uso
---

Estos documentos deben ser consultados:

- Al inicio del proyecto para entender contexto e identidad
- Durante onboarding de nuevos miembros del equipo
- Antes de modificar la estructura documental
- Durante auditorías de calidad documental
- Para resolver ambigüedades sobre clasificación o alcance
