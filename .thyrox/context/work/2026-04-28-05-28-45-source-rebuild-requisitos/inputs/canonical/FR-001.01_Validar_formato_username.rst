FR-001.01: Validar formato username
===================================

2. Especificación
-----------------

**Declaración:**

   El sistema DEBE validar que el campo username cumpla con el formato
   requerido CUANDO el usuario envía el formulario de login.

**Descripción:**

   Antes de consultar la base de datos, el sistema valida que el username
   ingresado cumpla con las reglas de formato establecidas:
   
   - Longitud mínima: 3 caracteres
   - Longitud máxima: 50 caracteres
   - Caracteres permitidos: alfanuméricos, guion bajo, punto
   - No puede iniciar con número
   - No puede contener espacios

----

3. Criterio de Aceptación
-------------------------

::

   DADO un usuario en la pantalla de login
   CUANDO ingresa un username y envía el formulario
   ENTONCES el sistema valida el formato antes de verificar credenciales
   
   Escenario 1: Username válido
   DADO username = "juan.perez_01"
   CUANDO se envía el formulario
   ENTONCES el sistema procede a verificar credenciales
   
   Escenario 2: Username muy corto
   DADO username = "ab"
   CUANDO se envía el formulario
   ENTONCES el sistema muestra "Username debe tener mínimo 3 caracteres"
   
   Escenario 3: Username con caracteres inválidos
   DADO username = "juan@perez"
   CUANDO se envía el formulario
   ENTONCES el sistema muestra "Username contiene caracteres no permitidos"

----

4. Reglas y Restricciones
-------------------------

- **BR aplicables:** Ninguna específica
- **CNST aplicables:** CNST-005 (Seguridad DRF)

**Notas de Seguridad:**

- La validación se realiza tanto en frontend como backend
- Mensajes de error no revelan información sobre existencia de usuarios
- Se sanitiza input para prevenir inyección
